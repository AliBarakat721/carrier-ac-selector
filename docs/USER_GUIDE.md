# دليل استخدام Carrier AC Selector

## 1. عن البرنامج

برنامج **Carrier AC Selector — HAP Report Analyzer** يساعدك على تحليل تقارير برنامج HAP واختيار وحدات تكييف Carrier المناسبة للحمل المطلوب. يستطيع البرنامج قراءة تقارير HAP بصيغ متعددة، استخراج حمل التبريد وتدفق الهواء، تصفية كتالوج Carrier، اقتراح وحدة أو أكثر، ثم تصدير النتائج إلى Excel أو Word أو CSV.

البرنامج يتضمن أيضًا أدوات إضافية لحساب جدول الأحمال الكهربائية بصورة تقديرية، وتحليل العائد من استخدام وحدات Inverter مقارنة بالوحدات Fixed Speed.

> **تنبيه:** نتائج اختيار الوحدة والحسابات الكهربائية وROI هي أدوات مساعدة لاتخاذ القرار وليست بديلًا عن مراجعة مهندس التكييف أو الكهرباء وبيانات الشركة المصنعة.

## 2. متطلبات التشغيل

### Windows

- Windows 10 أو Windows 11.
- Python 3.10 أو أحدث، ويفضل Python 3.12.
- اتصال بالإنترنت عند أول تشغيل لتنزيل المكتبات.
- برنامج Tesseract OCR اختياري، لكنه مطلوب لقراءة الصور وملفات PDF الممسوحة ضوئيًا.

### Linux وmacOS

- Python 3.10 أو أحدث.
- PySide6 وبقية المكتبات الموجودة في `requirements.txt`.
- Tesseract OCR اختياري للصور وملفات PDF الممسوحة.

لخطوات تثبيت Windows المصورة، راجع قسم التثبيت في [README.md](../README.md).

## 3. التثبيت والتشغيل

### 3.1 التشغيل السهل على Windows

1. نزّل المشروع من GitHub باستخدام **Code → Download ZIP**.
2. فك الضغط باستخدام **Extract All**. لا تشغّل البرنامج من داخل نافذة ZIP المضغوط.
3. ثبّت Python من الموقع الرسمي، وفَعّل اختيار **Add Python to PATH**.
4. افتح المجلد الناتج بعد فك الضغط.
5. اضغط مرتين على:

   ```text
   Start_Carrier.bat
   ```

6. في أول تشغيل، ينشئ البرنامج البيئة الافتراضية `.venv` وينزل المكتبات المطلوبة ويتحقق من التثبيت.
7. يحاول البرنامج إنشاء اختصار باسم **Carrier AC Selector** على سطح المكتب.
8. بعد اكتمال الإعداد تفتح الواجهة تلقائيًا.

يجب الاحتفاظ بمجلد المشروع في مكانه بعد إنشاء الاختصار؛ لأن الاختصار يعتمد على مسار هذا المجلد. إذا لم يتم إنشاء الاختصار بسبب صلاحيات Windows أو إعدادات سطح المكتب، يمكنك تشغيل `Start_Carrier.bat` مرة أخرى أو تشغيل `run.ps1` من PowerShell.

### 3.2 التشغيل اليدوي على Windows باستخدام PowerShell

افتح PowerShell داخل مجلد المشروع وشغّل:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1
.\run.ps1
```

لتشغيل الاختبارات:

```powershell
.\test.ps1
```

### 3.3 التشغيل على Linux أو macOS

من داخل مجلد المشروع:

```bash
./setup.sh
./run.sh
```

أو يدويًا:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt -r requirements-dev.txt
python main.py
```

## 4. تشغيل Tesseract OCR

يحتاج البرنامج إلى Tesseract فقط في الحالات التالية:

- رفع صورة PNG أو JPG أو JPEG أو BMP أو TIFF.
- رفع ملف PDF عبارة عن صور ممسوحة ضوئيًا بدون Text Layer.

لا يحتاج البرنامج إلى Tesseract عند قراءة:

- ملفات RTF.
- ملفات PDF التي تحتوي على نص قابل للتحديد والنسخ.

### Windows

ثبّت Tesseract باستخدام مُثبت Windows المناسب، ثم أضف مجلد التثبيت إلى PATH. المسار الشائع هو:

```text
C:\Program Files\Tesseract-OCR
```

بعد تعديل PATH أغلق PowerShell وافتحه من جديد. عند تشغيل البرنامج سيظهر تحذير إذا لم يجد Tesseract، لكن باقي وظائف البرنامج ستظل متاحة.

## 5. فهم الواجهة الرئيسية

تنقسم الواجهة إلى قسمين:

### القسم الأيسر

يحتوي على:

- **Upload HAP Report:** رفع تقرير HAP.
- **Image Preview:** معاينة الصورة أو الصفحة الأولى من PDF.
- **Extracted Load Data:** القيم التي استخرجها OCR.
- **Verify Values:** إدخال أو تصحيح القيم قبل البحث.
- **Confirm & Search:** تأكيد القيم وتشغيل البحث.
- **Clear All:** مسح التقرير والنتائج وإعادة الحقول إلى حالتها الابتدائية.

### القسم الأيمن

يحتوي على:

- **Filters & Options:** فلاتر البحث وعوامل الأمان.
- تبويب **Results:** نتائج الوحدات المطابقة.
- تبويب **Multi-Unit:** اقتراح وحدات متطابقة عند عدم كفاية وحدة واحدة.
- تبويب **Systems:** تحليل تقارير HAP التي تحتوي على عدة أنظمة.
- تبويب **Selected:** سلة الوحدات المختارة من أنظمة مختلفة.
- تبويب **Inverter ROI:** تحليل التوفير وفترة الاسترداد.
- تبويب **Electrical:** جدول الأحمال الكهربائية التقديري.
- تبويب **OCR Debug:** النص الخام الناتج من OCR لتشخيص أخطاء القراءة.

قد لا تظهر تبويبات **Inverter ROI** أو **Electrical** إذا كانت الوحدة البرمجية المقابلة غير مثبتة، لكن التثبيت العادي من ملفات المتطلبات يثبتها تلقائيًا.

## 6. رفع تقرير HAP

1. اضغط **Upload HAP Report**.
2. اختر ملفًا من الصيغ التالية:

   ```text
   PDF, RTF, PNG, JPG, JPEG, BMP, TIFF
   ```

3. انتظر انتهاء شريط التقدم.
4. يضع البرنامج القيم المستخرجة في حقول:
   - `BTU/hr`
   - `CFM`
   - `Sensible`
5. راجع القيم يدويًا قبل الضغط على **Confirm & Search**.

يبحث البرنامج داخل قسم **Central Cooling Coil** عن:

- `Total coil load` لاستخراج حمل التبريد.
- `Coil CFM at Design` أو القيم البديلة المناسبة لاستخراج تدفق الهواء.
- قيمة الحمل المحسوس إن كانت متاحة.

لا يستخدم البرنامج أرقامًا عامة من التقرير عند عدم وجود السطر المطلوب؛ بل يعرض تحذيرًا حتى لا يتم اختيار وحدة بناءً على قيمة غير مؤكدة.

## 7. إدخال القيم وتصحيح OCR

### BTU/hr

أدخل حمل التبريد الكلي بوحدة Btu/hr، مثل:

```text
82800
82,800
```

### CFM

أدخل تدفق الهواء التصميمي بوحدة CFM، مثل:

```text
2663
2,663
```

### Sensible

هذا الحقل اختياري. أدخل الحمل المحسوس بوحدة Btu/hr إذا كان موجودًا في تقرير HAP. يستخدمه البرنامج لإظهار حالة **Sensible OK**، ولا يستخدمه كبديل عن حمل التبريد الكلي.

### تأكيد القيم

اضغط **Confirm & Search** بعد مراجعة القيم.

- يجب إدخال قيمة BTU/hr أو CFM على الأقل.
- إذا أدخلت CFM فقط، سيطلب البرنامج تأكيدًا لأن النتائج لن تُفلتر حسب سعة التبريد.
- إذا أدخلت BTU/hr فقط، سيبحث البرنامج حسب السعة ويهمل فلتر الهواء.
- إذا كانت القيم غير صحيحة أو سالبة، سيظهر تنبيه لإعادة إدخالها.

## 8. الفلاتر وعوامل الاختيار

توجد الفلاتر داخل مجموعة **Filters & Options**، وتتغير النتائج تلقائيًا عند تعديلها.

| الحقل | الوظيفة |
|---|---|
| **Category** | اختيار فئة المنتج أو عرض كل الفئات من خلال `All Categories`. |
| **Type** | التصفية حسب نوع الوحدة مثل Heat Pump أو Cool Only أو النوع الموجود في الكتالوج. |
| **Series** | التصفية حسب سلسلة Carrier. |
| **Power** | التصفية حسب مصدر الكهرباء مثل `220V / 1Ph` أو `380V / 3Ph`. |
| **Safety Factor** | هامش إضافي على حمل التبريد المطلوب، من 0% إلى 30% في الواجهة. |
| **Min CFM** | النسبة الدنيا من CFM المطلوب التي يجب أن تغطيها الوحدة، من 50% إلى 100%. |
| **Derating** | تخفيض السعة الاسمية لمراعاة ظروف التصميم ودرجة الحرارة، من 0% إلى 30%. |

### مثال

إذا كان الحمل 80,000 Btu/hr وSafety Factor يساوي 10%، يصبح الحمل المطلوب للمقارنة:

```text
80,000 × 1.10 = 88,000 Btu/hr
```

إذا كان CFM يساوي 2,000 وMin CFM يساوي 85%، فالحد الأدنى لتدفق الهواء هو:

```text
2,000 × 0.85 = 1,700 CFM
```

إذا كان Derating يساوي 10%، يتم استخدام السعة الفعالة التالية في المقارنة:

```text
السعة الفعالة = السعة الاسمية × 0.90
```

## 9. تبويب Results

يعرض تبويب **Results** كل الوحدات المفردة التي تحقق متطلبات الحمل والهواء بعد تطبيق الفلاتر.

أهم الأعمدة:

- `Category`
- `Series`
- `System Model`
- `Cooling (Btu/hr)`
- `Excess %`
- `Airflow (CFM)`
- `CFM Cover %`
- `EER`
- `Sensible`
- `Cooling (Tons)`
- `Cooling (kW)`
- `Indoor Unit`
- `Outdoor Unit`
- `Type`
- `Power Supply`

### تفسير النتائج

- الصف الأخضر هو الوحدة الأقل زيادة في السعة ضمن النتائج الأولية.
- `Excess %` يوضح مقدار زيادة سعة الوحدة عن الحمل الأساسي.
- `CFM Cover %` يوضح نسبة تغطية تدفق الهواء المطلوب.
- الرمز `≈` بجانب CFM يعني أن قيمة CFM تقريبية في الكتالوج.
- علامة `✔` في Sensible تعني أن السعة المحسوسة التقديرية تغطي الحمل المحسوس.
- علامة `✘` تعني أن فحص الحمل المحسوس لم ينجح ويجب مراجعة الاختيار.
- يمكن الضغط على عنوان أي عمود لترتيب النتائج.
- يمكن سحب حدود الأعمدة لتوسيعها أو تصغيرها.
- الضغط مرتين على صف ينسخ `System Model`.

### اختيار عدة صفوف

- استخدم `Ctrl + Click` لاختيار صفوف منفصلة.
- استخدم `Shift + Click` لاختيار نطاق من الصفوف.
- بعد الاختيار اضغط **Export Selected** لتصدير الوحدات المحددة فقط.

## 10. اختيار أفضل وحدة

توجد مجموعة **Pick the Best Unit** داخل تبويب Results:

### Best Overall

يستخدم تقييمًا متوازنًا يجمع بين:

- قلة الزيادة في السعة.
- ارتفاع EER.
- قرب تغطية الهواء من 100%.

### Least Oversized

يختار أصغر وحدة ما زالت تغطي الحمل المطلوب، أي أقل `Excess %`.

### Most Efficient

يختار الوحدة ذات أعلى قيمة `EER (Btu/Wh)` من الوحدات المطابقة.

### Best Airflow

يختار أقرب تغطية لتدفق الهواء إلى 100%، مع تفضيل الوحدة التي لا تقل عن الحد المطلوب.

### Export Picked

بعد الضغط على أحد أزرار الاختيار، اضغط **Export Picked** لتصدير الوحدة المختارة فقط إلى Excel أو Word أو CSV.

إذا لم تضغط زرًا من أزرار الاختيار، يمكنك تحديد صف يدويًا ثم استخدام **Export Picked**.

## 11. تبويب Multi-Unit

إذا لم توجد وحدة واحدة تغطي الحمل، يعرض تبويب **Multi-Unit** مجموعات من وحدات متطابقة.

يعرض الجدول:

- عدد الوحدات `# Units`.
- موديل الوحدة.
- السعة المفردة والإجمالية.
- تدفق الهواء المفرد والإجمالي.
- نسبة الزيادة.
- EER والنوع.

البرنامج يبحث عن أقل عدد من الوحدات المتطابقة، بحد أقصى أربعة حسب إعدادات المحرك.

### الاستخدام

1. اضبط الفلاتر أولًا.
2. افتح تبويب **Multi-Unit**.
3. راجع الصف الأخضر أو اختر صفًا آخر.
4. اضغط **Add to Selection** لإضافة المجموعة إلى السلة.
5. استخدم **Export Multi-Unit** لتصدير كل البدائل.

## 12. تبويب Systems للتقارير متعددة الأنظمة

عند رفع تقرير HAP كامل يحتوي على أكثر من Air System، يكتشف البرنامج الأنظمة تلقائيًا ويعرضها في تبويب **Systems**.

يدعم البرنامج صيغ العناوين التالية:

- `Air System Sizing Summary for ...`
- `Air System Information ... Air System Name ...`

### طريقة الاستخدام

1. ارفع التقرير الكامل.
2. انتظر انتهاء OCR أو استخراج النص.
3. افتح تبويب **Systems**.
4. راجع اسم كل نظام وحمله وCFM وحالة المطابقة.
5. اضغط على صف نظام للانتقال إلى نتائج هذا النظام.
6. استخدم **Previous** و**Next** للتنقل بين الأنظمة.
7. استخدم **View Results** لفتح نتائج النظام المحدد.
8. بعد اختيار وحدة مناسبة اضغط **Add to Selection**.
9. صدّر الملخص باستخدام **Export Systems Summary**.

### حالات النظام

- `Single unit`: توجد وحدة واحدة مطابقة.
- حالة تشير إلى وجود عدة وحدات: لا تكفي وحدة واحدة ويجب مراجعة Multi-Unit.
- `No match`: لا توجد مطابقة ضمن الفلاتر الحالية.
- `Not parsed`: لم يتم استخراج حمل تبريد صالح لهذا النظام.

إذا ظهرت `No match`، جرّب تقليل Safety Factor أو Derating أو Min CFM، أو أزل فلاتر Category وType وSeries وPower للتحقق من توفر بديل.

## 13. تبويب Selected وسلة الاختيارات

تبويب **Selected** يجمع وحدات لأنظمة مختلفة في ملف واحد.

### إضافة وحدة

1. اختر نظامًا من تبويب Systems أو استخدم تقريرًا منفردًا.
2. اختر وحدة من Results أو استخدم Multi-Unit.
3. اضغط **Add to Selection**.
4. ستظهر الوحدة في تبويب **Selected**.

### إدارة السلة

- **Remove Selected:** حذف الصفوف المحددة من السلة.
- **Clear Selection:** حذف كل محتويات السلة.
- **Export All Selected (One File):** تصدير كل الوحدات في ملف واحد.

السلة تحتفظ بعدد الوحدات في حالة اختيار Multi-Unit، مثل `2x`.

## 15. تبويب Inverter ROI

يستخدم تبويب **Inverter ROI** لمقارنة وحدة Fixed Speed مع وحدة Inverter.

### Operating Conditions

- `Cooling Load (BTU/hr)`: الحمل المراد تحليله.
- `Units Count`: عدد الوحدات.
- `Hours / Day`: ساعات التشغيل اليومية.
- `Days / Year`: عدد أيام التشغيل السنوية.
- `Tariff & Currency`: سعر الكهرباء ووحدة العملة.

### Equipment Costs

- `Fixed Speed Price`: سعر الوحدة التقليدية.
- `Inverter Unit Price`: سعر وحدة Inverter.
- `Install Delta (Total)`: فرق تكلفة التركيب الكلي.
- `Price Premium`: الزيادة الأولية في تكلفة Inverter.

### Efficiency • Lifecycle

- `Energy Saving %`: نسبة التوفير المفترضة.
- `System Lifetime`: العمر الافتراضي بالسنوات.
- `CO₂ Factor (kg/kWh)`: معامل الانبعاثات.

### قراءة النتائج

يعرض البرنامج:

- القدرة الكهربائية.
- الاستهلاك السنوي بالكيلووات ساعة.
- تكلفة الكهرباء السنوية.
- تكلفة الشراء الأولية.
- فترة الاسترداد `Payback Period`.
- التوفير خلال العمر الافتراضي.
- كمية CO₂ المتجنبة.
- توصية مالية مبنية على القيم المدخلة.

هذه النتائج تعتمد بالكامل على الافتراضات التي تدخلها. لا تعتبر نسبة التوفير قيمة مضمونة من الشركة المصنعة.

الأزرار المتاحة:

- **Copy (Markdown):** نسخ النتائج كنص Markdown.
- **Export ROI Sheet:** إنشاء ملف Excel مستقل للتحليل.
- **Reset:** إعادة القيم الافتراضية.

## 16. تبويب Electrical

تبويب **Electrical** يحسب جدول أحمال كهربائية تقديريًا للوحدات الموجودة في السلة أو الوحدة النشطة.

### Electrical Parameters

- `Power Factor (cos φ)`: معامل القدرة.
- `Diversity Factor`: معامل التنوع للأحمال.
- `Ambient Temp (°C)`: درجة الحرارة المحيطة.
- `Distance to Panel`: المسافة إلى اللوحة.
- `Installation Method`: طريقة التركيب، مثل Conduit أو Tray أو Buried.
- `Grouped Circuits`: عدد الدوائر المجمعة.

### Main Feeder & Panel Sizing

يعرض البرنامج:

- إجمالي الحمل المتصل.
- تيار الطلب التصميمي.
- القاطع الرئيسي MCB.
- كابل التغذية الرئيسي.
- المولد الاحتياطي.
- حجم اللوحة المقترح.

### Unit-by-Unit Electrical Distribution Schedule

يعرض لكل وحدة:

- System Tag.
- Model.
- Qty.
- Power.
- Supply.
- FLA.
- MCB.
- Cable Sizing.
- Voltage Drop.
- Status.

### التحذيرات

قد يظهر Status مثل `Review` أو تحذيرات عند:

- استخدام تيار تقديري بدل تيار الكتالوج.
- عدم توفر MCA/MOCP.
- تجاوز أكبر قاطع أو كابل موجود في الجداول.
- تجاوز حد هبوط الجهد.
- وجود أحمال أحادية وثلاثية الأوجه مختلطة.

الأزرار المتاحة:

- **Copy Schedule (MD):** نسخ الجدول كنص Markdown.
- **Export Electrical Sheet:** إنشاء ملف Excel مستقل.

> لا تستخدم جدول الكهرباء كاعتماد نهائي للتنفيذ. راجع nameplate وMCA وMOCP وكود الكهرباء المحلي مع المهندس المسؤول.

## 17. تبويب OCR Debug

يعرض تبويب **OCR Debug** النص الخام الذي أعاده Tesseract أو النص المستخرج من PDF/RTF.

استخدمه عندما:

- لم يتم استخراج BTU أو CFM.
- ظهرت قيمة غير منطقية.
- كان التقرير يحتوي على أكثر من نظام.
- تريد معرفة ما إذا كان OCR قرأ العناوين بشكل صحيح.

ابحث في النص عن:

```text
Central Cooling Coil
Total coil load
Coil CFM at Design
Air System Sizing Summary for
```

إذا كانت الكلمات أو الأرقام مشوهة، أدخل القيم يدويًا في Verify Values بدل الاعتماد على OCR.

## 18. حل المشاكل الشائعة

### البرنامج لا يفتح عند الضغط على Start_Carrier.bat

1. تأكد من تثبيت Python 3.10 أو أحدث.
2. افتح PowerShell واكتب:

   ```powershell
   python --version
   ```

3. تأكد من وجود اتصال بالإنترنت عند أول تشغيل.
4. جرّب تشغيل:

   ```powershell
   .\setup.ps1
   .\run.ps1
   ```

5. إذا كانت البيئة ناقصة، احذف مجلد `.venv` ثم شغّل `Start_Carrier.bat` مرة أخرى.

### لا يظهر اختصار سطح المكتب

هذا لا يمنع تشغيل البرنامج. استخدم `Start_Carrier.bat` أو `run.ps1`. تأكد من أن Windows يسمح بإنشاء ملفات `.lnk` وأن مجلد Desktop موجود في حساب المستخدم.

### تظهر رسالة Python غير موجود

ثبّت Python من الموقع الرسمي مع تفعيل **Add Python to PATH**، ثم أغلق PowerShell وافتحه من جديد.

### OCR لا يقرأ الصورة

1. ثبّت Tesseract.
2. أضف `C:\Program Files\Tesseract-OCR` إلى PATH.
3. افتح PowerShell جديدًا.
4. جرّب تشغيل:

   ```powershell
   tesseract --version
   ```

5. إذا استمر الخطأ، أدخل BTU وCFM يدويًا.

### PDF لا يظهر له Preview

قد لا يظهر Preview إذا كان PDF تالفًا أو لا يمكن تحويل الصفحة الأولى إلى صورة. جرّب فتح الملف في قارئ PDF، أو استخدم ملفًا آخر. إذا كان PDF يحتوي على Text Layer، قد يستمر استخراج النص حتى لو تعذر Preview.

### لا توجد نتائج

جرّب بالترتيب:

1. راجع BTU وCFM.
2. قلّل `Safety Factor`.
3. قلّل `Derating`.
4. قلّل `Min CFM` مؤقتًا للتشخيص.
5. أزل فلاتر Category وType وSeries وPower.
6. راجع تبويب Multi-Unit.

### لا يمكن استبدال ملف Excel أو Word

أغلق الملف من Excel أو Word، وتأكد من أن مجلد الحفظ يسمح بالكتابة، ثم أعد التصدير باسم جديد.

### تظهر نتائج كهربائية مع تحذير Review

هذا متوقع عندما تكون بيانات التيار أو الحماية غير موجودة في الكتالوج. راجع القيم مع بيانات nameplate والمهندس الكهربائي.

## 20. ملاحظات هندسية مهمة

- السعة الاسمية في الكتالوج ليست دائمًا السعة الفعالة عند ظروف التصميم.
- `Derating` يقلل السعة المستخدمة في فحص المطابقة.
- فحص Sensible يعتمد على نسبة تقديرية، وليس منحنى أداء كامل من الشركة المصنعة.
- EER وROI لا يمثلان بالضرورة أداء الحمل الجزئي الحقيقي.
- الحسابات الكهربائية تقديرية وقد تستخدم FLA محسوبًا من القدرة وEER عند عدم توفر تيار الشركة المصنعة.
- القاطع المقترح لا يثبت توافق MCA/MOCP.
- مطابقة هبوط الجهد لا تثبت المطابقة الحرارية أو تحمل تيار القصر أو زمن الفصل أو متطلبات الكود.
- الأحمال المختلطة 1-Phase و3-Phase تحتاج إلى توزيع فعلي على L1/L2/L3.
- قبل التنفيذ، يجب مراجعة nameplate وMCA وMOCP ومسارات الكابلات ودرجة الحرارة وطريقة التركيب والتأريض والكود المحلي.

للتفاصيل الهندسية، راجع [ENGINEERING_CALCULATION_LIMITATIONS.md](ENGINEERING_CALCULATION_LIMITATIONS.md).
