# HAP Integration and Unit System

## Room-level extraction

`core.parse_hap_rooms(text, source_file=...)` extracts a list of `HapRoom` records. Each value is represented by `ExtractedValue` and contains:

- normalized value and explicit unit;
- `status`: `EXTRACTED`, `MISSING`, or `NOT_VERIFIED`;
- `SourceRef` with source filename, inferred page marker, line range, and text excerpt when available.

Supported room fields are Room Name, Room Number, Total Cooling Load, Sensible Load, Latent Load, Heating Load, Supply Airflow, Room Area, Zone, and Design Conditions. The parser supports common HAP labels and normalizes capacity to Btu/h, airflow to CFM, and area to m².

A missing field is not replaced with zero as a verified engineering value. Legacy `HapResult.btu`, `cfm`, and `sensible_btu` fields remain available for the existing selection UI.

## Thermal validation

`core.thermal_validate(total_btu, sensible_btu, latent_btu)` checks:

```text
QTotal = QSensible + QLatent
```

The default tolerance is 2% of the total load. The result contains `VALID`, `WARNING`, or `NOT_VERIFIED`, together with the signed difference in Btu/h, absolute difference percentage, and a human-readable message.

A warning means the report values were extracted but are inconsistent. It does not silently replace one value with another.

## Source traceability

Pass the original path to the parser:

```python
result = core.parse_hap_text(text, source_file="design_report.pdf")
rooms = core.parse_hap_rooms(text, source_file="design_report.pdf")
```

The desktop application now passes the uploaded HAP path into the parser. For PDF text generated by the existing OCR front-end, page markers such as `--- page 3 of 8 ... ---` are used to infer the page number.

## Central unit conversions

`units.py` is the single conversion module. Canonical functions include:

- `cooling_capacity_to_btu_h` / `btu_h_to_cooling_capacity`: Btu/h, kW, TR;
- `airflow_to_l_s` / `l_s_to_airflow`: CFM, L/s, m³/h;
- `length_to_m` / `m_to_length`: mm, cm, m, inch, ft;
- `pressure_to_pa` / `pa_to_pressure`: Pa, kPa, psi;
- `temperature_to_c` / `c_to_temperature`: °C, °F;
- `area_to_m2` / `m2_to_area`: m², ft².

Invalid or non-finite inputs raise `UnitConversionError`. New engineering code should use these functions rather than duplicating conversion constants.

## Limitations

HAP reports vary by version, export format, OCR quality, and language. A successful extraction is not an approval of the design. The application still requires human review against the original report, especially where a field is `MISSING`, `NOT_VERIFIED`, or thermal validation is `WARNING`.
